# Product Requirements

## Product
sBLOOM Template & Content Hub

## Core purpose
An internal creative asset platform where authorized users can add, organize, discover, reuse, and remix templates/assets.

## Roles
- Admin
- Contributor (combines content consumption and contribution capabilities)

## MVP capabilities
1. Authentication and roles
2. Generic Asset model
3. User asset upload
4. Storage and processing
5. Approval workflow
6. Library
7. Search and filters
8. Asset detail and preview
9. My Work
10. Saved assets and collections
11. Remix/duplicate/versioning
12. Usage tracking
13. Migration of the existing 28 templates

## Initial asset types
Website Template, Social Post, Carousel, Reel/Video, Story, Presentation, Document, Other.

## Lifecycle
Draft → Processing → Needs Review → Approved → Published → Archived

## Core success criterion
A contributor can add a new template without changing source code, and another authorized user can find, preview, save, use, and remix it.
