# Phase Audit Protocol

## Inputs
Antigravity completion report, changed files/repository state, test results, screenshots/video when relevant, known issues, deferred work.

## Audit
Functional, architecture, data, UX, accessibility, security, reliability, testing.

## Verdicts
**PASS** — criteria satisfied and no blockers.
**PASS WITH FIXES** — only minor non-blocking issues.
**FAIL** — blocking defect, incomplete core behavior, architecture violation, or security/data-integrity issue.

## Output
What passed, what failed, P0/P1/P2 issues, required fixes, regression risks, and whether the next phase may begin.
