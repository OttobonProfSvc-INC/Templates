# Project Rules

- Implement one approved phase at a time.
- A phase is complete only after audit approval.
- Do not implement future phases early.
- User-added assets are a core MVP capability.
- Existing 28 templates are seed data only.
- Asset types must remain extensible.
- Production data must not be hard-coded.
- Do not fake functionality with UI placeholders.
- Authentication and authorization must be enforced server-side.
- Validate uploads and isolate untrusted previews.
- Document significant architecture decisions.
