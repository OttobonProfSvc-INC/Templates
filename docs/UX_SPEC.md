# UX Specification

## Primary navigation
- Library
- Add Asset
- My Work
- Collections

Admin: Review Queue, Users.

## Library
Search, filters, sorting, asset cards/list, loading, empty and error states.

## Asset detail
Preview, title, type, metadata, creator, version, status, Save, Use, Remix.

## Add Asset
Progressive disclosure; only necessary fields are mandatory. AI suggestions must be editable and clearly marked until verified.

## Accessibility
Keyboard navigation, visible focus, semantic controls, labels, appropriate ARIA, non-color status cues, contrast, responsive layouts.
