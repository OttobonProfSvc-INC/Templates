# User Flows

## Add Asset
Add Asset → Select files → Select type → Basic metadata → Upload → Processing → Review → Submit → Approved → Published.

## Discover
Library → Search/filter → Results → Asset detail → Preview → Save / Use / Remix.

## Remix
Published asset → Remix → New asset/version → Modify → Save. The original remains unchanged.

## Review
Contributor → Submit → Needs Review → Admin → Approve or Reject.

## My Work
Uploads / Drafts / Saved / Recently Used / Remixes.

## Collection
Create collection → Add assets → Manage collection.
