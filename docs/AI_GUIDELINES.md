# AI Guidelines

AI is an enhancement, not a dependency for core reliability.

## Initial use
Suggest asset type, industry, platform, audience, objective, tone, tags, and description. Human users can edit and approve.

## Later
Semantic search, recommendations, similarity, controlled remix, content generation.

## Rules
AI never authorizes users, never decides permissions, and never silently publishes generated content. Record AI-generated and human-verified metadata. Core workflows must work when AI is unavailable.
